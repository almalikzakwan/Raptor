# Raptor Framework
A modern, secure, and high-performance Python web framework inspired by Laravel, built on top of flask.  
  
## Overview
Raptor is a lightweight web framework built on top of Flask, designed to provide Laravel-like development experience while maintaining Flask's flexibility and performance. Help by AntiGravity AI.
  
The framework focuses on: 
- High Performance  
- Secure by default  
- Laravel-Inspired Project Structure  
- Easy Development  
- Modular Architecture  
- Rapid Application Development  

## Why Raptor?
Flask is simple and flexible.  
  
## Features  
- [x] Laravel-Inspired Routing Facade.  
- [x] Context-Based Route Middleware & Grouping.  
- [x] Centralized Middleware Kernel.  
- [x] MVC Architecture Structure.  
- [x] Active Record ORM & MySQL Database Integration. 
- [x] Environmental Configuration.  
- [x] Migration & Seeding System.  
  
## Installation  
Clone the repository.  
```  
git clone https://<username>:<token>@github.com/almalikzakwan/Raptor.git  
cd raptor
python -m venv .venv # if you want to use virtual environment
.venv\Scripts\activate
```  
if you are using linux,  
```
source .venv/bin/activate
```
  
Install dependencies.  
```
pip install -r requirements.txt
```
  
Run the development server.  
```
npm run start-dev
```
